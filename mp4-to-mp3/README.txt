========================================
  MP4 转 MP3 工具（Windows 7 32位 可用）
========================================

【用途】
把 MP4 视频批量提取音频，转换成 MP3。整个工具零安装、
零依赖，使用 Windows 自带的 mshta.exe 运行界面，
用随包携带的 ffmpeg.exe 完成转换。

【系统要求】
- Windows 7 32 位（及以上）
- 无需安装 Python、.NET 或任何运行库

【文件说明】
mp4-to-mp3\
  MP4转MP3.hta   ← 双击这个文件打开程序
  bin\
    ffmpeg.exe    ← 需要你自己放入（见 bin 里的说明文件）
  README.txt      ← 本说明

【第一次使用：放入 ffmpeg.exe】
1. 打开 bin 文件夹，按里面的说明下载 32 位版 ffmpeg。
2. 把 ffmpeg.exe 复制到 bin 文件夹，路径为 bin\ffmpeg.exe。
   （若缺少此文件，程序会提示并禁止开始转换。）

【使用步骤】
1. 双击 “MP4转MP3.hta”。
2. 点击 “选择文件夹”，选中存放 MP4 的文件夹。
3. 程序会显示发现的 MP4 数量。
4. 选择音质（128 / 192 / 320 kbps，默认 192）。
   如需连同子文件夹一起转换，勾选 “包含子文件夹”。
5. （可选）勾选 “输出到指定目录”，把所有 MP3 集中输出到
   你选择的文件夹；不勾选则输出到每个 MP4 所在目录。
6. 点击 “开始转换”，进度条与日志会实时更新。
7. 转换完成后弹窗显示 “成功 X 个，失败 Y 个”。
   若勾选了 “完成后打开文件夹”，会自动打开输出所在目录。

【输出位置】
- 默认：MP3 与原 MP4 同目录、同名，已存在同名 MP3 会被覆盖。
- 勾选 “输出到指定目录”：全部输出到该目录；若出现重名
  （例如不同子文件夹里有同名 MP4），会自动加序号
  （如 名称_1.mp3）避免覆盖。

【高级选项】
高级选项默认展开显示在界面上，点击 “收起高级选项” 可折叠隐藏：
- 跳过前面 X 秒：去掉音频开头的 X 秒（如片头/广告）。
- 跳过后面 X 秒：去掉音频结尾的 X 秒（如片尾）。
- 剪切后再重复拼接成 2 遍：先按上面设置剪切，
  再把剪切后的音频连续播放 2 遍（时长翻倍）。
  处理顺序为：先剪切，后拼接。
  注意：该选项默认不勾选，即默认只输出一遍剪切后的音频；
  如需两遍请手动勾选。此设置不会被记住，每次打开程序
  都恢复为默认不勾选。
- 转换成功后将原 MP4 文件移入回收站：转换完成后把对应的
  MP4 源文件移入回收站（不是永久删除，可从回收站还原）。
  为防误操作，勾选时会弹出提示框要求二次确认；
  点“取消”则不勾选。仅处理“转换成功”的源文件，
  转换失败的会保留以免丢失。
填 0 或不勾选即不启用对应功能。

【ffmpeg 版本要求】
高级选项中的“跳过后面”和“重复拼接”需要 ffmpeg 3.2 及以上
版本（含 aloop/areverse 滤镜）。若使用过旧版本，这两项
可能报错导致转换失败，请下载较新的 32 位版本。

【调试日志（排错用）】
界面下方有 “记录调试日志” 开关，默认关闭，不影响正常使用。
- 开启后，程序会把详细诊断信息追加写入程序目录下的
  debug.log，包括：选择的文件夹与文件清单、转换参数、
  音频滤镜，以及实际生成的每一条 ffmpeg 命令。
- 排查问题时：勾选该开关，重新操作一次，再把 debug.log
  发给维护者即可。
- 日志体积控制：debug.log 超过 2MB 时会自动截断——
  删除最旧的内容、仅保留最新约 20 万字符（按完整行保留），
  并在开头写入标记行 “[日志超过 2MB，已截断旧内容，
  仅保留最新记录]”，因此文件不会无限增大。
- 注意：debug.log 写在程序所在目录，请确保该目录可写
  （如桌面、下载文件夹）；若放在只读目录（如 Program Files）
  则日志无法生成。

【常见问题】
- 打开时提示未找到 ffmpeg：请确认 bin\ffmpeg.exe 存在，
  且是 32 位版本。
- 某个文件转换失败：会记入日志的 [FAIL]，不影响其他文件继续转换。
  常见原因是该 MP4 文件损坏或不含音轨。
- 界面为空白/报脚本错误：请确认系统为 Windows 7 及以上，
  并直接双击 .hta 文件运行（不要用记事本等打开）。
- 转换出错需要排查：见上方【调试日志（排错用）】。

【技术说明（可忽略）】
- 界面：HTA（HTML + JScript），由系统 mshta.exe 运行。
- 转换：程序在系统临时目录生成一个批处理文件，异步（最小化）
  调用 ffmpeg 逐个转换，并把进度写入临时日志；界面每 0.5 秒
  读取日志刷新进度。
- ffmpeg 命令：
  ffmpeg -y -i "输入.mp4" -vn -acodec libmp3lame -ab <码率>k "输出.mp3"
